# Termion

Лёгкий SSH-клиент для Windows. В нём только то, чем пользуешься каждый день: дерево сессий, терминал, файлы на сервере и макросы.

Termion — обычная десктопная программа для Windows, а не веб-приложение: у неё свой `.exe`, своё окно и значок на панели задач.

## Скачать

Последняя версия — на странице [Releases](https://github.com/CoilNovaTeam/Termion/releases/latest). Там два файла:

- **`Termion-Setup-<версия>.exe`** — установщик, рекомендуется.
  - Ставится в один щелчок для текущего пользователя, права администратора не нужны.
  - Создаёт ярлыки на рабочем столе и в меню «Пуск».
  - Новая версия ставится поверх старой.
  - Удалить можно через «Параметры → Приложения».
- **`Termion-<версия>-portable.exe`** — без установки, например для флешки. При каждом запуске распаковывается во временную папку, поэтому открывается секунд 8–10.

Сессии, пароли и настройки хранятся в `%APPDATA%\Termion`. Они общие для обоих вариантов и сохраняются при обновлении и удалении программы.

Программа не подписана сертификатом. Поэтому при первом запуске Windows может показать «Система Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».

## Что уже работает

### Макросы (этап 3)

Макрос — это сохранённая команда или набор команд. По щелчку Termion печатает их в терминал вкладки так, как будто вы набрали их сами.

**Полоса макросов под терминалом**
- В полосе только макросы, которые относятся к открытой вкладке. Щелчок выполняет макрос, правый щелчок открывает меню: выполнить, изменить, дублировать, удалить.
- Порядок кнопок меняется перетаскиванием.
- Кнопка «⋯» справа показывает все макросы, в том числе не относящиеся к этой вкладке, чтобы их можно было найти и изменить.
- Во вкладке редактора макрос выполняется в терминале, из которого открыт файл.
- Полосу можно скрыть в настройках. Горячие клавиши работают и без неё.

**Окно макроса** (кнопка «Макрос» на панели инструментов, «+ Макрос» в полосе, «Новый макрос для сессии…» или «…для папки…» в меню дерева сессий)
- **Команды** — по одной на строку. Отступы сохраняются, пустые строки в конце отбрасываются.
- **«Нажать Enter после последней строки»** — если снять галочку, последняя команда только напечатается. Так удобно для опасных команд: сначала проверите, потом запустите сами.
- **Где показывать:**
  - везде;
  - только в терминалах компьютера;
  - в сессиях папки, включая вложенные папки;
  - в одной сессии.

  Если папку или сессию удалили, макрос не пропадает: он виден везде и помечен «папка удалена».
- **Пауза между строками** — от 0,3 до 5 секунд, для команд, которые ждут ввода (`sudo`, пароль, подтверждение). Пока макрос с паузами печатается, его кнопка подсвечена. Повторный щелчок останавливает макрос, оставшиеся строки не печатаются. Если связь оборвётся, макрос остановится сам.
- **Горячая клавиша** — нажмите сочетание в поле, и оно запишется:
  - для букв и цифр нужны два модификатора, например `Ctrl+Alt+1` или `Ctrl+Shift+5`;
  - для `F1`–`F12` достаточно одного, например `Ctrl+F5`;
  - одиночные `Ctrl+…` и `Alt+…`, а также голые F-клавиши заняты: они нужны bash, nano, vim и mc на сервере;
  - одно сочетание может быть только у одного макроса;
  - сочетание срабатывает только там, где макрос виден.

**Выполнить после входа.** В настройках сессии есть поле «После входа выполнить». Выбранный макрос выполняется сам после каждого подключения к этой сессии, в том числе после переподключения. Например: `cd /var/www/app && git status`, `sudo -i`, `docker ps`.

Макросы хранятся в `macros.json`. Пароли в макросах лучше не держать: файл не шифруется.

### Файлы на сервере и редактор (этап 2)

**Дерево файлов**
- Файлы сервера по SFTP — через то же подключение, что и терминал, без повторного входа.
- Папки раскрываются щелчком, двойной щелчок по папке — войти в неё, по файлу — открыть в редакторе.
- Строка пути: переход по частям пути, «наверх», «домой»; двойной щелчок по пути — ввести путь вручную (`~/app`, `/etc/nginx`, путь к файлу).
- **Следование за терминалом:** после `cd` в терминале дерево переходит в ту же папку, а после каждой команды тихо обновляется. Работает с bash в Ubuntu/Debian и Fedora/RHEL (по заголовку окна) и с оболочками, которые сообщают папку через OSC 7.
- «Перейти сюда в терминале» — отправляет в терминал `cd` в выбранную папку.
- Создание файлов и папок, переименование (`F2`), удаление (`Delete`) с подтверждением. Системные папки (`/etc`, `/usr`…) и домашнюю папку целиком удалить нельзя. Ссылка удаляется как ссылка — то, на что она указывает, не трогается.
- Скрытые файлы показываются чуть бледнее (можно выключить), символические ссылки — со стрелкой.
- Управление с клавиатуры: стрелки, `Enter`, `Backspace` (наверх), `F2`, `Delete`, `F5`, `Home`/`End`, `PageUp`/`PageDown`.
- Папки на тысячи файлов открываются быстро: в окне рисуются только видимые строки.

**Выделение и перетаскивание**
- Несколько файлов и папок сразу: `Ctrl+щелчок`, `Shift+щелчок`, `Shift+стрелки`, `Ctrl+A`. Внизу панели видно, сколько выделено и сколько весят файлы; `Esc` снимает выделение.
- Меню для выделенного: скачать всё на компьютер, скопировать пути, удалить одним подтверждением.
- Перемещение мышью внутри дерева: перетащите файлы на папку (если задержать курсор над свёрнутой папкой, она раскроется). Перед перемещением Termion спрашивает — вопрос можно отключить галочкой «Больше не спрашивать» или в настройках.
- Перетаскивание в Проводник или на рабочий стол:
  - файл приходит как есть;
  - папка или несколько объектов приходят одним zip-архивом. Windows не даёт обычной программе «пообещать» при перетаскивании папку, а один файл — можно. Чтобы получить папки как есть, используйте «Скачать на компьютер»;
  - Проводник ждёт, пока файл скачается с сервера, поэтому недокачанный файл не появится, сколько бы он ни весил. Прогресс виден в панели файлов, там же передачу можно отменить;
  - у файлов, имя которых начинается с точки, при перетаскивании пропадает точка (`.env` придёт как `env`) — так Chromium обращается с загрузками. Чтобы имя сохранилось, используйте «Скачать на компьютер».

**Передача файлов**
- Скачивание файлов и целых папок на компьютер, загрузка на сервер — кнопкой, из меню или перетаскиванием из Проводника прямо в нужную папку дерева.
- Прогресс и отмена в панели файлов, «Показать в папке» для скачанного.
- Недокачанный файл никогда не выдаётся за готовый: данные пишутся во временный файл и переименовываются только в конце. Если файл уже есть — вопрос: заменить, пропустить или отменить.

**Редактор**
- Встроенный редактор (CodeMirror) во вкладках рядом с терминалами: подсветка для конфигов nginx и systemd, `.env`, YAML, JSON, shell, Python, JS/TS, HTML/CSS, SQL, Dockerfile и других; язык определяется и по строке `#!`.
- Поиск и замена (`Ctrl+F`, `Ctrl+H`), переход к строке (`Ctrl+G`), отмена, сворачивание блоков, несколько курсоров, перенос строк (`Alt+Z`).
- Кодировка и окончания строк сохраняются как были: UTF-8, UTF-8 с BOM, Windows-1251; LF или CRLF. Их можно сменить в строке состояния.
- **Безопасное сохранение (`Ctrl+S`):**
  - если файл изменили на сервере после открытия (другой человек или программа), Termion не затрёт эти изменения молча, а спросит: перезаписать или загрузить новую версию;
  - запись атомарная — сначала временный файл, затем мгновенная подмена, поэтому при обрыве связи файл не останется наполовину записанным; права и владелец файла сохраняются;
  - если атомарно нельзя (нет прав на папку), запись идёт прямо в файл;
  - через символическую ссылку сохраняется настоящий файл, ссылка остаётся ссылкой.
- Несохранённые изменения не теряются: при закрытии вкладки, терминала или всей программы — вопрос «Сохранить?».
- Двоичные файлы и файлы больше 5 МБ не открываются как текст — вместо этого предлагается скачать.

### Терминалы компьютера

- Кнопка **«+»** у вкладок открывает меню: терминалы этого компьютера и новое SSH-подключение.
- Termion сам находит установленные оболочки: PowerShell 7, Windows PowerShell, командную строку, Git Bash, MSYS2, Cygwin и дистрибутивы WSL (служебные дистрибутивы Docker Desktop скрыты).
- `Ctrl+Shift+T` — терминал по умолчанию. Какой именно, выбирается в настройках.
- Работают через настоящий псевдотерминал Windows (ConPTY): цвета, `vim`, `htop` в WSL, изменение размера окна, кириллица.
- Копирование, вставка, шрифты и темы — как у SSH-вкладок. После `exit` нажмите Enter, и терминал запустится заново.

### Сведения о сервере

- **В строке состояния** у подключённой вкладки — загрузка процессора, занятая память и свободное место на основном диске. При 75% индикатор становится жёлтым, при 90% — красным.
- **Щелчок по индикаторам** (или «Сведения о сервере» в меню вкладки) открывает подробную сводку:
  - система: имя, версия ОС, ядро, тип виртуализации, сколько работает без перезагрузки;
  - процессор: модель, число ядер, загрузка с графиком, средняя нагрузка за 1, 5 и 15 минут;
  - память и подкачка;
  - все диски: сколько свободно и сколько всего (служебные tmpfs, snap и overlay Docker не показываются);
  - сеть: адреса интерфейсов (щелчок копирует) и текущая скорость приёма и отдачи;
  - самые загруженные процессы — по процессору или по памяти;
  - контейнеры Docker и их состояние, если Docker установлен и у пользователя есть к нему доступ.
- **Как собираются сведения:** отдельным каналом того же подключения, без повторного входа. Используются только команды чтения: `/proc`, `df`, `ip`, `who`, `docker ps`. В истории команд и в терминале ничего не появляется. Опрашивается только сервер вкладки на экране и только пока окно не свёрнуто. Строка состояния обновляется раз в 5 секунд, открытая сводка — раз в 2,5 секунды.
- Полные сведения — для Linux. На других системах показывается то, что удалось узнать. Если сервер разрешает только SFTP, сводка так и скажет.
- Индикаторы в строке состояния можно отключить в настройках.

### Сессии и терминал (этап 1)

**Сессии**
- Дерево сессий с папками: создание, изменение, удаление, дублирование.
- Перетаскивание сессий и папок мышью.
- Поиск по названию, адресу и логину (`Ctrl+K`).
- Управление с клавиатуры: стрелки, `Enter`, `F2`, `Delete`.
- В поле адреса можно вставить строку вида `user@host:port` — она сама разберётся по полям.

**Терминал**
- SSH-терминал во вкладках (xterm.js, отрисовка через WebGL), 256 цветов, Unicode.
- Встроенные шрифты Cascadia Mono и JetBrains Mono.
- Копирование и вставка как в Windows:
  - `Ctrl+C` копирует, если что-то выделено; иначе — обычное прерывание программы;
  - `Ctrl+V` вставляет;
  - есть копирование сразу при выделении и вставка правым кликом (как в PuTTY).
- Ссылки открываются по `Ctrl+клик`.

**Вход**
- По паролю.
- По SSH-ключу: форматы OpenSSH и PuTTY (`.ppk`), ключи с фразой-паролем, стандартные ключи из `~/.ssh` подхватываются автоматически.
- Через ssh-agent.
- keyboard-interactive (в том числе двухфакторный вход).
- Если ключ не подошёл, Termion предложит войти по паролю.

**Безопасность**
- Ключ сервера проверяется при каждом подключении. Termion учитывает и свой список доверенных серверов, и `~/.ssh/known_hosts` от OpenSSH. Если ключ сервера сменился, появится заметное предупреждение.
- Пароли и фразы-пароли хранятся в зашифрованном виде (защищённое хранилище Windows) отдельно от списка сессий. Сохраняются только после успешного входа.
- Окно программы изолировано от системы, все запросы из окна проверяются.

**Надёжность**
- Понятные сообщения об ошибках подключения.
- Автоматическая проверка связи: «зависшее» соединение распознаётся.
- Переподключение — клавишей `Enter` во вкладке.
- Огромный вывод (логи, `cat` большого файла) не подвешивает окно.
- Файлы данных записываются атомарно, с резервной копией. Повреждённый файл восстанавливается из копии и не теряется.

**Оформление**
- Три темы: «Графит», «Классика», «Светлая».
- Три раскладки: «Слева стопкой», «Как в MobaXterm», «Файлы справа».
- Настройки шрифта и курсора, изменяемая ширина панели.
- Программа запоминает размер и положение окна.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+K` | Поиск сессий |
| `Ctrl+Shift+N` | Новая сессия |
| `Ctrl+Shift+T` | Терминал компьютера (PowerShell, CMD, Git Bash, WSL — какой выбран в настройках) |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующая / предыдущая вкладка |
| `Ctrl+Shift+W` | Закрыть вкладку |
| `Ctrl+Shift+D` | Дублировать вкладку |
| `Ctrl+Shift+R` | Переподключиться (в редакторе — перечитать файл с сервера) |
| `Ctrl+Alt+1`, `Ctrl+F5`… | Макросы — те сочетания, которые вы им назначили |
| `Ctrl+,` | Настройки |
| `Ctrl+C` / `Ctrl+V` | Копировать выделенное / вставить |
| `Ctrl+S` | Сохранить файл (во вкладке редактора) |
| `Ctrl+F` / `Ctrl+H` / `Ctrl+G` | Поиск / замена / переход к строке в редакторе |
| `Alt+Z` | Перенос длинных строк в редакторе |

Сочетания работают при любой раскладке клавиатуры. `Ctrl+W`, `Ctrl+N` и другие намеренно не заняты: они нужны программам на сервере (bash, nano, vim). `Ctrl+S` в терминале тоже уходит на сервер — сохранение файла срабатывает только во вкладке редактора.

## Где хранятся данные

`%APPDATA%\Termion`:

| Файл | Что внутри |
|---|---|
| `sessions.json` | список сессий и папок (без паролей) |
| `secrets.json` | пароли и фразы ключей, зашифрованные средствами Windows; на другом компьютере бесполезны |
| `known_hosts.json` | ключи серверов, которым вы доверяете |
| `macros.json` | макросы (не шифруется — паролей в макросах лучше не держать) |
| `settings.json` | настройки |
| `window-state.json` | размер и положение окна |
| `logs\main.log` | журнал программы (без паролей и содержимого терминала) |

Перед каждой записью предыдущая версия сохраняется в `.bak`.

## Разработка

Нужен Node.js 22.12 или новее.

```bash
npm install          # зависимости (Electron скачается автоматически)
npm run dev          # запуск с горячей перезагрузкой интерфейса
npm test             # unit- и интеграционные тесты (с локальным SSH-сервером)
npm run typecheck    # строгая проверка типов
npm run e2e          # сквозной тест настоящего окна программы (скриншоты — в test-results/e2e)
npm run dist         # быстрая сборка для проверок: dist/win-unpacked/Termion.exe
npm run dist:exe     # установщик и переносимый exe: dist/Termion-Setup-<версия>.exe, dist/Termion-<версия>-portable.exe
```

### Новая версия

Сборку и публикацию в Releases делает GitHub Actions ([`.github/workflows/release.yml`](.github/workflows/release.yml)). Запускается тегом:

```bash
npm version patch          # 0.1.0 → 0.1.1: исправления (minor — 0.2.0: новые возможности)
git push --follow-tags     # коммит и тег v0.1.1 уходят на GitHub
```

`npm version` поднимает версию в `package.json`, делает коммит и ставит тег; рабочая папка должна быть закоммичена. Дальше GitHub сам:

1. проверяет, что тег совпадает с версией;
2. прогоняет проверку типов и тесты;
3. собирает оба exe;
4. выкладывает релиз.

Это занимает минут 10–15, ход сборки виден на вкладке Actions. Если что-то не прошло, релиза не будет. Тогда исправьте ошибку и выпустите следующую версию.

Дополнительные проверки:
- `TERMION_REAL_SSH=user@host npm test` — проверка на настоящем сервере OpenSSH. Используются ключи из `~/.ssh` и только чтение `known_hosts`. На сервере выполняется `echo`, читается список `/`, а сохранение файлов проверяется во временной папке `/tmp/termion-test-*`, которая удаляется в конце.
- `TERMION_E2E_EXE=dist/win-unpacked/Termion.exe node scripts/e2e.mjs` — сквозной тест собранной программы.

Макет дизайна лежит в [`design/mockup.html`](design/mockup.html).

## Стек

- Electron 45, TypeScript 7, React 19.
- [xterm.js](https://xtermjs.org/) — терминал.
- [CodeMirror 6](https://codemirror.net/) — редактор; модули языков подгружаются, только когда открыт файл такого типа.
- [ssh2](https://github.com/mscdex/ssh2) — SSH и SFTP, на чистом JavaScript.
- [node-pty](https://github.com/microsoft/node-pty) — терминалы компьютера через ConPTY. Ставится готовой сборкой (N-API), пересобирать под Electron не нужно.
- electron-vite — сборка, electron-builder — упаковка.
