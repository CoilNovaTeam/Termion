# Termion

Лёгкий SSH-клиент для Windows. В нём только то, чем пользуешься каждый день: дерево сессий, терминал, файлы на сервере и макросы.

Termion — обычная десктопная программа для Windows, а не веб-приложение: у неё свой `.exe`, своё окно и значок на панели задач. В браузере открывается только макет дизайна.

## Статус

Идёт этап дизайна. Макет интерфейса лежит в [`design/mockup.html`](design/mockup.html): откройте файл в браузере, в макете всё кликабельно.

## Что войдёт в первую версию

- Дерево сохранённых сессий с папками.
- SSH-терминал во вкладках.
- Дерево файлов на сервере (SFTP):
  - переход по папкам;
  - открытие, создание, переименование и удаление файлов;
  - встроенный редактор.
- Макросы: общие, для папки или для отдельной сессии, с горячими клавишами.
- Хранение паролей и ключей в защищённом хранилище Windows.
- Импорт сессий и макросов из MobaXterm.

## Стек (план)

Electron, TypeScript, xterm.js (терминал), ssh2 (SSH и SFTP), CodeMirror (редактор).
